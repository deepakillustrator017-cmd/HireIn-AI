**Fields:** `salary_min`/`salary_max` are NULL (shown as *Not disclosed*) because none of these employers publish salaries on their postings. `experience` is taken from the posting text ("Not specified" when the posting doesn't state it). `responsibilities`/`requirements`/`benefits` come from the posting's own sections; when a posting has no such section the field points the candidate to the official posting.
